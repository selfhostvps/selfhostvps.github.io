## reality

- Github：https://github.com/wulabing/xray_docker
- 数据库依赖：无
- 中文版：无
- 开销：
	- CPU < 1%
	- 内存 < 20 MB
	- Docker Image：34 MB
	- 本地存储：0
- 当前最新版本：0.0.34
- 默认 docker 端口号：443
- 本网站分配的端口号：5507

**docker compose 目录结构**

```
/DOCKERS/xray_reality_5507
└── docker-compose.yml # 配置文件
```

**docker-compose.yml**

```
services:
  xray_reality_5507:
    image: wulabing/xray_docker_reality:latest
    container_name: xray_reality_5507
    restart: always
    ports:
      - 5507:443
    environment:
      - EXTERNAL_PORT=5507
    networks:
      - network_expose
networks:
  network_expose:
    external: true
```
